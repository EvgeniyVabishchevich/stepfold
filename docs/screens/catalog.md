# Бриф каталога и выбора цели

C5в, 20.11.2026. Пользователь находит прогрессию во вкладке «Каталог», видит её главы и выбирает, на какую копить шаги. Сохранённая цель появляется на экране «Сегодня». Выбор медалей остаётся будущим шагом.

## Данные

- `Catalog.index(language)` даёт виды, группы длины, прогрессии и главы. Группу каждой прогрессии определяет `lengthOf`.
- `ProgressRepository.watch()` даёт текущую цель и открытые главы. `SetGoal` проверяет и сохраняет выбор.
- Правила порядка глав, смены цели и доступа к скрытым прогрессиям описаны в [продуктовых решениях](../product.md). Индекс содержит названия и цены. Изображения приходят в содержимом главы и отображаются общим `CatalogImage` на экране чтения.

## Состояния и действия

| Состояние | Что видит и может сделать пользователь |
| --- | --- |
| Загрузка | Заглушка списка каталога. |
| Каталог загружен | Виды, прогрессии и выбор длины. Можно перейти к списку глав прогрессии. |
| Пусто | Сообщение о пустом каталоге или отсутствии прогрессий выбранной длины. Во втором случае можно изменить фильтр. |
| Каталог недоступен | Сообщение с действием «Повторить». |
| Главы прогрессии | Названия и цены глав в шагах, текущая цель и статусы глав. Для доступной главы можно выбрать цель. Нажатие на открытую главу ведёт в чтение. |
| Прогрессия недоступна | Сообщение о недоступной прогрессии и возможность вернуться к списку. |
| Ошибка сохранения цели | Сообщение об ошибке. Можно повторить выбор после сбоя хранилища. Если глава стала недоступной, показываем актуальное состояние прогрессии. |

## Навигация — решено 20.11.2026

Нажатие на прогрессию открывает отдельный экран с её главами внутри вкладки «Каталог». Кнопка «Назад» возвращает к списку прогрессий.
