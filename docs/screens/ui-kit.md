## Цель

Основа, из которой собираются все экраны: токены и базовые компоненты, которые есть почти везде. По ним потом пишется тема в коде. Остальное кит получает по ходу: каждый экранный шаг сначала добавляет в него недостающие компоненты, потом собирает экран ([порядок](../design.md#порядок-работы)).

## Токены

- **Цвет.** Пять цветов из design.md плюс недостающие роли:
  - текст и значки на акценте;
  - разделитель и граница;
  - неактивное;
  - ошибка;
  - бронза, серебро и золото для медалей, приглушённые.
  
  Имена ролей — как в `ColorScheme` Material 3 (`primary`, `onPrimary`, `surface`, `onSurface`, `outline`, `error`…). Свои роли, например медали, — отдельными токенами. Так тема в коде переносится один к одному.
- **Отступы** на сетке 4: 4, 8, 12, 16, 24, 32.
- **Радиусы**: `small` 12 (кнопки, мелкое), `card` 20, `sheet` 28, `full` 999 (полностью скруглённое: полоса прогресса; в коде — `StadiumBorder`).
- **Текст** — Inter. Стили:
  - главная фраза экрана;
  - заголовок;
  - подзаголовок;
  - основной текст;
  - подпись;
  - крупное число.
  
  У чисел цифры одинаковой ширины (tabular figures), чтобы счётчик шагов не прыгал.

## Компоненты и состояния

| Компонент | Состояния |
| --- | --- |
| Нижняя навигация, вкладки по [карте экранов](../product.md) | вкладка выбрана / нет |
| Верхняя панель | с «назад» / без; с действием справа |
| Кнопка: основная, второстепенная, текстовая | обычная, нажата, неактивна, загрузка |
| Полоса прогресса | идёт, набрано, долг |
| Заглушки состояний | пусто (с действием), загрузка (скелетон), ошибка (с «Повторить») |

## Чего не делаем

- Не рисуем экраны и компоненты конкретных экранов: карточки, строки, листы, диалоги. Они появятся на шагах C5б–C5г. Черновик «Сегодня» пересобирается из кита на шаге C5б.
- Источники и правила выбора значков описаны в [гайдлайнах дизайна](../design.md#иконки--обновлено-24112026).
- Анимации не описываем.

## Готово, когда

- Обе темы собраны из переменных, ни одного цвета в обход токенов.
- Каждый компонент есть во всех состояниях из таблицы.
- Контраст текста от 4.5:1 в обеих темах, зона касания от 48×48.
- Есть страница-витрина: все компоненты рядом в светлой и тёмной теме, со скриншотами.
