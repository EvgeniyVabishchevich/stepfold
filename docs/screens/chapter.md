# Бриф экрана чтения главы

C5б, согласовано 18.11.2026. После успешного открытия глава показывается на отдельном экране поверх вкладок. Кнопка «Назад» возвращает на «Сегодня» с обновлённым запасом и целью.

## Данные

- Заголовок главы берём из `Catalog.index(language)`.
- `Catalog.chapterContent(progressionId, chapterId, language)` даёт блоки в порядке чтения. Показываем прокручиваемый текст, картинки с подписями и подписи точек маршрута. Для Путешествий с геометрией добавляем [карту](#карта-путешествия-c6).

## Состояния и действия

| Состояние | Что видит и может сделать пользователь |
| --- | --- |
| Загрузка | Верхняя панель с кнопкой «Назад» и заглушка текста. |
| Глава загружена | Название и блоки главы. Пользователь может прокрутить их и вернуться на «Сегодня». |
| Пустое содержимое | Сообщение о том, что содержимое главы отсутствует, и возможность вернуться. |
| Каталог недоступен | Сообщение с кнопкой «Повторить». Повтор загружает содержимое уже открытой главы без новой траты. |
| Глава не найдена | Сообщение о недоступной главе и возможность вернуться. |

## Макет

Кадры чтения находятся на [странице макета «Сегодня»](today.md#материалы-для-макета). Верхняя панель и заглушки — из UI-кита. В примерах использованы текст главы «Шторм» и иллюстрация из «Мозаики рассвета». Есть кадры для обеих тем, загрузки, ошибки, недоступной и пустой главы.

## Карта Путешествия (C6)

Цель — показать, до какой точки маршрута дошёл читатель. В «Золотом кольце» пять остановок, по одной на главу. Для линии вдоль реальных дорог используем [геометрию маршрута из каталога](../architecture.md#карта-путешествия-c6--решено-24112026).

Правило [позиции между остановками](../product.md#идея--решено-09112026) согласовано 24.11.2026. В макете нужно различить достигнутую остановку и предварительную метку на следующем участке. Например, при запасе 3 000 из 6 000 шагов метка стоит на половине пути от Сергиева Посада до Переславля. Если шагов уже хватает, но глава ещё закрыта, предварительная метка совпадает со следующей остановкой. При чтении ранее открытой главы карта показывает актуальный прогресс всего путешествия.

| Состояние | Что видит читатель |
| --- | --- |
| Глава загружается | Та же заглушка, что у остальных глав. |
| Маршрут доступен | Карта над текстом главы, линия маршрута, достигнутая остановка и предварительная метка, если выбрана следующая остановка. Карту можно приблизить и сдвинуть. |
| Не загрузилась подложка карты | Маршрут и метки остаются видны на нейтральном фоне. Текст главы доступен. |
| Нет данных маршрута | Глава открывается со своим текстом и иллюстрациями, как обычно. |
