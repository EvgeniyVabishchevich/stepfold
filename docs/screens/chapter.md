# Бриф экрана чтения главы

C5б, согласовано 18.11.2026. После успешного открытия глава показывается на отдельном экране поверх вкладок. Кнопка «Назад» возвращает на «Сегодня» с обновлённым запасом и целью.

## Данные

- Заголовок главы берём из `Catalog.index(language)`.
- `Catalog.chapterContent(progressionId, chapterId, language)` даёт блоки в порядке чтения. В C5б показываем прокручиваемый текст и картинки с подписями. Для точки маршрута достаточно подписи, если она есть. Карта запланирована на C6.

## Состояния и действия

| Состояние | Что видит и может сделать пользователь |
| --- | --- |
| Загрузка | Верхняя панель с кнопкой «Назад» и заглушка текста. |
| Глава загружена | Название и блоки главы. Пользователь может прокрутить их и вернуться на «Сегодня». |
| Пустое содержимое | Сообщение о том, что содержимое главы отсутствует, и возможность вернуться. |
| Каталог недоступен | Сообщение с кнопкой «Повторить». Повтор загружает содержимое уже открытой главы без новой траты. |
| Глава не найдена | Сообщение о недоступной главе и возможность вернуться. |

## Макет

Кадры чтения находятся на [странице макета «Сегодня»](today.md#материалы-для-макета). Верхняя панель и заглушки — из UI-кита. В примерах использованы текст главы «Шторм» и иллюстрация из «Мозаики рассвета». Есть кадры для обеих тем, загрузки, ошибки, недоступной и пустой главы.
