# Бриф истории шагов

C5г, 20.11.2026. История открывается из «Сегодня» внутри той же вкладки. Пользователь видит, сколько шагов было по дням, и может исправить пропущенный подсчёт ручной добавкой.

## Данные

- `ProgressRepository.watch()` даёт день установки, шаги счётчика и ручные добавки за день, а также открытия для недельной сводки.
- `AddManualSteps` проверяет и сохраняет ручную добавку. Состояние запрета описано моделью `ManualEntryLock`.
- Состав графика, списка и сводки задан в [продуктовых правилах](../product.md). Пример строки с ручной добавкой — `4 500 + 3 000 вручную`.

## Состояния и действия

| Состояние | Что видит и может сделать пользователь |
| --- | --- |
| Загрузка | Заглушки графика и списка. |
| История загружена | График, недельная сводка и список дней. У дней с ручной добавкой показано её значение. |
| Шагов ещё нет | Пустое состояние. Ручной ввод доступен, если разрешён. |
| История недоступна | Сообщение и действие «Повторить». |
| Ручной ввод | Можно добавить, исправить или удалить добавку за разрешённый день, в том числе за день без показаний счётчика. Для большой добавки показываем подтверждение. |
| Ввод запрещён | История доступна для просмотра. После запроса на разблокировку показываем время, когда ввод снова станет доступен. |
| Не удалось сохранить | Сообщение об отказе или ошибке хранилища. После ошибки хранилища можно повторить действие. |

Правила диапазона дат, подтверждения и задержки разблокировки — в разделе «Правила продвижения» [продуктового документа](../product.md).

## Хранение запрета — решено 20.11.2026

Храним запрет вместе с прогрессом. Схему и условия установки описали в [архитектуре](../architecture.md#хранение-запрета-ручного-ввода-c5г--20112026).

## Сводка и график

График показывает дни текущей недели с понедельника по воскресенье. Сводка считает период с понедельника по сегодня по местной дате. Сравнение появится, если шагов больше, чем за те же дни прошлой недели, и оба периода покрыты с даты установки. Если несколько дней делят первое место, показываем первый из них.

Для оценки расстояния берём 0,75 м на шаг. В сводке показываем один ориентир из [таблицы расстояний](../distance-facts.md). Названия глав и медалей берём из каталога. Пока каталог недоступен, указываем количество открытий.
